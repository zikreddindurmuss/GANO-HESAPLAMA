# GANO Calculator (C Language)

This project is a simple terminal-based General Grade Point Average (GANO) calculator written in C.

## 🚀 Project Description
The program allows users to enter course credits and letter grades, then calculates the General Weighted Grade Point Average (GANO) based on the standard 4.00 grading system.

It was developed as a practice project to strengthen fundamental C programming concepts such as:
- Variables and data types
- Conditional statements
- Loops
- User input/output
- Basic arithmetic operations

## 🛠️ Technologies Used
- C Programming Language
- GCC Compiler (or any C compiler)
